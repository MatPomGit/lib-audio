# Prywatność i retencja

Głos, transkrypcje oraz identyfikatory mówcy mogą być danymi osobowymi lub biometrycznymi. Nie przesyłać próbek, transkrypcji i metadanych identyfikujących uczestników do publicznego CI, Issues i Pages. Dla każdego badania niezależnie ustalać podstawę prawną, czas retencji, dostęp i dozwolony endpoint.

Rejestr sprzętowy i dane dostępowe należą do prywatnego repo `devices`. Tutaj można przechowywać kontrakty abstrakcyjne oraz dane syntetyczne, nie surowe wyniki pomiarów.
